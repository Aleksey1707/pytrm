# Метки триажа

Скиллы оперируют пятью каноническими ролями триажа. Этот файл сопоставляет роли с реальными строками меток, которые используются в трекере задач этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                        |
| ------------------------- | --------------------- | ----------------------------------------------- |
| `needs-triage`            | `needs-triage`        | Мейнтейнеру нужно оценить задачу                |
| `needs-info`              | `needs-info`          | Ждём от автора дополнительной информации        |
| `ready-for-agent`         | `ready-for-agent`     | Полностью описана, готова для AFK-агента        |
| `ready-for-human`         | `ready-for-human`     | Требует реализации человеком                    |
| `wontfix`                 | `wontfix`             | Не будет взята в работу                         |

Когда скилл упоминает роль (например, «поставь метку готовности для AFK»), используй соответствующую строку метки из этой таблицы.

Правую колонку можно править под любой словарь, который реально используется.
