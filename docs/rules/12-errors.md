- **Читать перед.** Новым исключением; правкой иерархии; добавлением `:raises` в документацию.
- **Словарь.** Плейсхолдеры и модальность — `00-index.md`.

## Иерархия

Корень — `BaseTrmException`. Между корнем и конкретным исключением стоит база подсистемы;
листья — конкретные ошибки. Подсистемы, которые есть сейчас: контекстный менеджер,
распространение, транзакция, реестр, настройки.

- Всё, что бросает пакет, MUST наследоваться от `BaseTrmException`: прикладной код ловит
  его одним `except` на границе.
- Промежуточные базы MUST быть абстрактными (`metaclass=abc.ABCMeta`) и MUST NOT бросаться
  напрямую — бросается лист.
- Новое исключение MUST попадать в существующую подсистему; новая база подсистемы заводится
  только вместе с новым слоем и отделяется в файле комментарием-разделителем, как соседние.
- Лист MUST NOT иметь наследников; если появился — он становится абстрактной базой.

```python
# плохо — лист наследуют, база не абстрактная
class SettingsNotFoundException(BaseTrmException):
    ...

class StrictSettingsNotFoundException(SettingsNotFoundException):
    ...

# хорошо — база подсистемы абстрактна, листья плоские
class BaseSettingsTrmException(BaseTrmException, metaclass=abc.ABCMeta):
    """Базовое исключение настроек"""

class SettingsNotFoundException(BaseSettingsTrmException):
    default_message = "Настройки не найдены"
```

## `default_message`

`BaseTrmException.__init__` подставляет `default_message`, если аргументы не переданы.

- У листа MUST быть заполнен `default_message`: исключение без текста нечитаемо в логе.
- Текст `default_message` MUST быть на русском и описывать факт, а не действие
  («Настройки не найдены», не «Проверьте настройки»).
- Динамические подробности передаются аргументом при возбуждении; `default_message` MUST
  оставаться константой без форматирования.
- У исключения с заполненным `default_message` docstring MAY отсутствовать: он дублировал бы
  тот же текст.

## Контракт `:raises`

Исключение — часть сигнатуры. Docstring публичного метода MUST перечислять исключения,
которые метод бросает сам или пропускает от вызываемых им методов.

- Строка пишется как `:raises <ИмяКласса>: <когда>` и идёт после `:return:`.
- При добавлении нового `raise` MUST обновляться docstring всех методов, через которые
  исключение выходит наружу; иначе контракт расходится с кодом.
- Ловить `BaseTrmException` внутри пакета SHOULD NOT: исключение либо обрабатывается по
  конкретному типу, либо пропускается наружу.

```python
# плохо — тип потерян, вызывающий не может разобрать причину
except exceptions.BaseTrmException:
    return None

# хорошо — ловится ровно тот случай, который умеем обработать
except exceptions.TransactionNotFoundInContextException:
    has_transaction = False
```
